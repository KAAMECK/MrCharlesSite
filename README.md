# MrCharlesSite — Usemi Vizuri Consulting

Site vitrine responsive de **Usemi Vizuri Consulting**, cabinet de conseil en stratégie de communication et influence.

## Aperçu local

Avec XAMPP démarré, ouvrir :

`http://localhost/MrCharlesSite/`

## Contenu à compléter

Les coordonnées, réseaux sociaux, références clients et liens non fournis sont volontairement indiqués par `#`.

## Structure

- `index.html` : contenu de la page
- `styles.css` : identité visuelle et responsive
- `script.js` : navigation mobile et interactions
- `assets/` : logo et visuel du site
- `Info/` : document de référence fourni
